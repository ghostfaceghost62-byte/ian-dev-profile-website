Website Privacy Policy

Last updated: October 2026. This policy governs your use of the Versagambit developer portfolio website.

Important Scope Distinction: This privacy policy applies solely to this developer portfolio website (the static web pages hosted at this domain). Each individual software application developed by Versagambit (including the upcoming Android application De Code AI) maintains its own distinct, standalone Application Privacy Policy tailored to its specific runtime permissions, local data storage, network requests, and AI service integrations.

1. Information We Collect on This Website

The Versagambit developer portfolio is engineered as a privacy-first static website:

  • No Analytics or Tracking Scripts: We do not deploy Google Analytics, Meta Pixel, tracking beacons, or third-party behavioral profiling scripts on this website.
  • No Cookies: This website does not set any first-party or third-party cookies in your browser. No cookie banners are required because no cookies are generated or stored.
  • No User Account Database: You do not need to register, log in, or provide personal credentials to browse any page of this website.

2. Direct Email Communications

If you choose to contact the developer directly via email or use the client-side email formatting assistant on our Contact page:

  • The information you provide (such as your name, email address, and message content) is transmitted directly through standard email protocols to our developer inbox: ghostfaceghost62@gmail.com.
  • This communication is never routed through an intermediary third-party marketing database or commercial lead broker.
  • Your contact information is used strictly to reply to your question, bug report, or inquiry. It is never sold, rented, or distributed to mailing lists.

3. Web Hosting & Infrastructure Logs

This website is hosted via static hosting infrastructure (such as GitHub Pages). Like virtually all web servers, the host infrastructure may temporarily collect standard technical server access logs (such as your IP address, browser user-agent, operating system, and request timestamps) to maintain network stability, prevent DDoS attacks, and comply with infrastructure security standards.

Versagambit does not combine or correlate these basic infrastructure logs with any individual identity.

4. Third-Party Links

This website may contain links to external sites, such as GitHub repositories, official documentation, or future Google Play Store listings once applications are released. We have no control over and assume no responsibility for the content, privacy policies, or practices of any third-party websites or services.

5. Mobile Application Privacy Policies (e.g. De Code AI)

When our Android applications (such as De Code AI) are published, they will have their own dedicated privacy policies accessible both within the app settings and via a direct link on their Google Play Store listing.

Those policies will explicitly outline:

  • Specific Android OS permissions requested (and why).
  • How source code snippets are processed (including local-only processing vs. secure API analysis).
  • Crash reporting or diagnostic parameters (if any).
  • Data retention and user deletion rights.

6. Policy Updates

If we introduce changes to this website in the future (for instance, if an integrated contact backend or search tool is added), this policy will be promptly updated with a revised "Last updated" date to reflect those changes accurately.
